## 📋 命令列表

### 1. `task` - 添加任务

#### 语法
```bash
task "标题" "时间" ["日期"]
```

#### 参数
- **标题**（必需）：任务标题
- **时间**（必需）：格式 `HH:MM`，例如 `14:30`
- **日期**（可选）：格式 `YYYY-MM-DD`，不提供则默认为今天

#### 示例

**添加今日任务**：
```bash
C:\WHATNOTE> task "写报告" "15:00"
```

**添加指定日期任务**：
```bash
C:\WHATNOTE> task "约医生" "10:00" "2024-11-10"
```

**添加带引号的任务**：
```bash
C:\WHATNOTE> task "讨论\"项目计划\"" "16:00"
```

---

### 2. `tasks` - 列出任务

#### 语法
```bash
tasks ["日期"]
```

#### 参数
- **日期**（可选）：格式 `YYYY-MM-DD`，不提供则显示今日任务

#### 示例

**查看今日任务**：
```bash
C:\WHATNOTE> tasks
```

**查看指定日期任务**：
```bash
C:\WHATNOTE> tasks 2024-11-10
```

**查看明天的任务**：
```bash
C:\WHATNOTE> tasks 2024-11-06
```

#### 输出说明
```
任务列表 (2024-11-05)
============================================================

 [✓] 09:00 晨会 (ID: 1730766000000)     # ✓ 表示已完成
 [ ] 14:30 开会 (ID: 1730783400000)     # [ ] 表示未完成
 [ ] 18:00 下班 (ID: 1730796000000)

共 3 个任务
```

---

### 3. `done` - 切换任务完成状态

#### 语法
```bash
done <任务ID> <日期>
```

#### 参数
- **任务ID**（必需）：任务的唯一ID（从 `tasks` 命令获取）
- **日期**（必需）：任务所在日期，格式 `YYYY-MM-DD`

#### 示例

**标记任务为已完成**：
```bash
# 1. 先查看任务列表获取ID
C:\WHATNOTE> tasks 2024-11-05
任务列表 (2024-11-05)
 [ ] 14:30 开会 (ID: 1730783400000)

# 2. 使用ID标记完成
C:\WHATNOTE> done 1730783400000 2024-11-05
任务状态已更新 → 已完成
```

**取消完成状态**（再次执行相同命令）：
```bash
C:\WHATNOTE> done 1730783400000 2024-11-05
任务状态已更新 → 未完成
```

## 🔧 高级工具（API风格）

除了简化命令，您还可以使用完整的 API 风格工具：

### `add_task` - 添加任务
```bash
C:\WHATNOTE> add_task date="2024-11-05" title="开会" time="14:30"
```

### `list_tasks` - 列出任务
```bash
C:\WHATNOTE> list_tasks date="2024-11-05"
```

### `toggle_task` - 切换完成状态
```bash
C:\WHATNOTE> toggle_task date="2024-11-05" task_id=1730783400000
```

### `delete_task` - 删除任务
```bash
C:\WHATNOTE> delete_task date="2024-11-05" task_id=1730783400000
```

### `search_tasks` - 搜索任务
```bash
# 搜索所有包含"会议"的任务
C:\WHATNOTE> search_tasks query="会议"

# 搜索日期范围内的任务
C:\WHATNOTE> search_tasks start_date="2024-11-01" end_date="2024-11-30"

# 仅搜索已完成的任务
C:\WHATNOTE> search_tasks completed=true
```

### `get_upcoming_tasks` - 获取即将到来的任务
```bash
# 获取未来7天的任务
C:\WHATNOTE> get_upcoming_tasks

# 获取未来14天的任务
C:\WHATNOTE> get_upcoming_tasks days=14

# 包含已完成的任务
C:\WHATNOTE> get_upcoming_tasks days=7 include_completed=true
```

## 💡 使用技巧

### 1. 快速添加今日任务
无需记住日期，直接使用两个参数：
```bash
C:\WHATNOTE> task "买菜" "18:00"
```

### 2. 获取任务ID
从 `tasks` 命令的输出中复制ID：
```bash
C:\WHATNOTE> tasks
 [ ] 14:30 开会 (ID: 1730783400000)  # ← 复制这个ID
```

### 3. 批量查看任务
使用 `search_tasks` 查看所有任务：
```bash
C:\WHATNOTE> search_tasks query=""
```

### 4. 查看本周任务
```bash
C:\WHATNOTE> get_upcoming_tasks days=7
```

### 5. 时间格式
- ✅ **正确**：`14:30`, `09:00`, `23:59`
- ❌ **错误**：`14:30:00`, `2:30`, `14`

### 6. 日期格式
- ✅ **正确**：`2024-11-05`, `2024-01-01`
- ❌ **错误**：`2024/11/05`, `11-05`, `05-11-2024`

## ❓ 常见问题

### Q: 为什么任务ID这么长？
A: 任务ID使用时间戳（毫秒），确保唯一性。您无需记住它，只需从 `tasks` 命令复制。

### Q: 可以删除任务吗？
A: 可以，使用完整的 API 风格命令：
```bash
delete_task date="2024-11-05" task_id=1730783400000
```

### Q: 如何查找某个任务？
A: 使用搜索命令：
```bash
search_tasks query="关键词"
```

### Q: 日历窗口和命令行任务是否同步？
A: 目前不同步。日历窗口使用 localStorage，命令行使用后端 JSON 文件。未来版本会实现同步。
