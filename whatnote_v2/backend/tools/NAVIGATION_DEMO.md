# 控制台导航系统演示

## 🎯 核心概念

控制台现在采用**类文件系统导航**，结构如下：

```
/                           (根目录)
├── 课程1/                  (课程目录)
│   ├── 展板A/              (展板目录 - 可执行窗口工具)
│   ├── 展板B/
│   └── 展板C/
├── 课程2/
│   ├── 展板X/
│   └── 展板Y/
└── 课程3/
```

## 🎯 关键优势

### 1. **用户友好**
- 用课程名/展板名导航，而不是长 ID
- 类似文件系统，学习成本低
- 提示符显示当前位置

### 2. **自动上下文**
- 在展板中时，工具自动使用当前 board_id
- 不需要每次输入长长的 ID

### 3. **清晰的层级**
```
/                    -> 可查看课程
/课程名               -> 可查看展板
/课程名/展板名        -> 可操作窗口
```

## 📋 命令速查表

### 导航命令
| 命令 | 功能 | 示例 |
|-----|------|-----|
| `pwd` | 显示当前路径 | `pwd` |
| `ls` | 列出当前内容 | `ls` |
| `courses` | 列出所有课程 | `courses` |
| `boards` | 列出当前课程的展板 | `boards` |
| `cd "名称"` | 进入课程/展板 | `cd "高等数学"` |
| `cd ..` | 返回上一级 | `cd ..` |
| `cd /` | 返回根目录 | `cd /` |

### 窗口工具（需在展板中）
| 命令 | 功能 | 是否需要 board_id |
|-----|------|-----------------|
| `get_windows` | 获取窗口列表 | ❌ 自动使用 |
| `create_window title="..."` | 创建窗口 | ❌ 自动使用 |
| `read_window window_id="..."` | 读取窗口 | ❌ 自动使用 |
| `update_window ...` | 更新窗口 | ❌ 自动使用 |
| `search_windows query="..."` | 搜索窗口 | ❌ 自动使用 |
| `delete_window window_id="..."` | 删除窗口 | ❌ 自动使用 |

## ❓ 常见问题

### Q: 如何知道我在哪里？
**A**: 
```bash
pwd                    # 显示当前路径
```
提示符也会显示当前路径！

### Q: 忘记了课程/展板的名字？
**A**:
```bash
courses                # 在根目录查看课程
boards                 # 在课程中查看展板
ls                     # 万能命令，自动显示当前可用内容
```

### Q: 课程/展板名字有空格怎么办？
**A**: 用引号包裹
```bash
cd "高等数学"           # 正确
cd 高等数学             # 错误！会被当作两个参数
```

### Q: 能直接跳转吗？
**A**: 暂不支持，需要逐级 cd：
```bash
# 不支持
cd "/高等数学/第一章"   # ❌

# 需要这样
cd "高等数学"
cd "第一章"             # ✅
```

### Q: 返回根目录最快方法？
**A**:
```bash
cd /                   # 一步到位
```

## 🎓 学习路径

**第一次使用:**
1. `help` - 看看有哪些命令
2. `courses` - 看看有哪些课程
3. `cd "课程名"` - 进入一个课程
4. `boards` - 看看有哪些展板
5. `cd "展板名"` - 进入展板
6. `get_windows` - 查看窗口
7. `tools` - 看看还能做什么

**熟练后:**
- 直接 `cd` 到目标展板
- 使用工具操作窗口
- 用 `cd ..` 或 `cd /` 快速切换
